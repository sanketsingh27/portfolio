# Domain docs

Layout: single-context.

Before exploring, read root CONTEXT.md and relevant ADRs
in docs/adr/. If CONTEXT-MAP.md exists later, follow its
pointers to relevant context documents.

If these documents do not exist, proceed silently.
Create them lazily when terminology or decisions are resolved.

Use the glossary's vocabulary when naming domain concepts.
Note real terminology gaps for domain-modeling.
Explicitly flag proposals that contradict an existing ADR.
